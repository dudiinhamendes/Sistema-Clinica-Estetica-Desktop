# 💄 Sistema para Clínica Estética

Sistema desktop desenvolvido durante o curso Técnico em Informática para gerenciamento de uma clínica estética.

## 📖 Sobre o projeto

Este projeto foi desenvolvido utilizando **Java** e **MariaDB**, com o objetivo de gerenciar as principais operações de uma clínica estética.

A aplicação implementa operações de **CRUD** para gerenciamento de clientes, serviços e agendamentos, utilizando o padrão **DAO (Data Access Object)** para organização do acesso aos dados.

## ✨ Funcionalidades

- Cadastro de clientes
- Cadastro de serviços
- Cadastro de agendamentos
- Edição e exclusão de registros
- Integração com banco de dados MariaDB

## 🛠️ Tecnologias utilizadas

- Java
- MariaDB
- SQL
- DAO (Data Access Object)

## 🎯 Objetivo

Aplicar conceitos de Programação Orientada a Objetos (POO), banco de dados relacionais e desenvolvimento de aplicações desktop.
